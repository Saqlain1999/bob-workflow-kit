# Reminder service planning fixture

This small standard-library project stores scheduled reminders as newline-delimited JSON. It is intentionally an inspection fixture: do not implement the requested feature. Read `REQUEST.md`, the current source, and the current tests, then replace the incomplete `DELIVERY_PLAN.md`.

The public evaluation checks selected evidence, acceptance, decision, traceability, and recovery properties. It cannot prove that a future implementation is correct.
